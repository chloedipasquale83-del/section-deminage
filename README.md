# Section Déminage

Jeu de déminage en équipe, en français : un démineur voit la bombe, l’expert a le carnet.

- **Solo** et **campagne « L’Horloger »** (14 missions, 7 régions).
- **Multijoueur à distance** : chacun sur son téléphone, synchronisé par un code de salon, sans compte (relais public MQTT).

Tout le jeu tient dans `index.html` (servi par GitHub Pages).
